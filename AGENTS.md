# DADA project

Use the gm skill and connected gm MCP for project work, including delegated work. Route discovery through gm codesearch and git operations through gm git verbs. Attribute commits only to the authenticated GitHub user.

The distributable skill lives in `skills/dada/`. `.agents/skills/dada` links to that directory for workspace installation. Keep required YAML frontmatter and `agents/openai.yaml` consistent with the `dada` name. The complete Mermaid graph lives in `references/anchor-graph.md`; preserve its node labels, edges and classes when maintaining packaging.

This package tracks the Graphic Design Agentic Workflow (gdaw); only the name changes to DADA and the graph is extracted into a reference. `skills/dada/SKILL.md` is the gdaw text verbatim apart from the title, the `name`/description prefix, and links to the graph reference. Resync from the newest gdaw text and diff the graph block against `references/anchor-graph.md`; they must stay identical, including the three `Autonomous mode` edge labels. The earlier unified no-modes edit is superseded by the gdaw version: Autonomous and Adaptive modes, the living Frontier, WHOLE rounds, stop conditions S1 to S5 and no move quota are the contract. Preserve the five required artifacts, independent contrasting critics, and objection resolution rules.

Validate skill metadata with the installed skill-creator quick_validate.py helper and check that relative references and the workspace discovery link resolve. Do not publish local gm state, machine configuration, credentials, or generated design logs.

Ten workflow amendments were pushed upstream into gdaw and then resynced here: the premortem WHOLE round R0 on any inherited artifact; "measure the move, assert on the computed value"; Step 2f deletion review plus the residual diff; S4 requiring a measured delta or a measured inert-lever finding; the Carry-Forward Ledger; that anti-skip line; the leverage tiebreak when Frontier candidates rank equal; Step 2g, re-measuring every figure the artifact prints at its final state before the stop test; and overruling an objection whose premise a measurement refuses instead of spending a move on it. If a resync reverts any of them, re-apply rather than accept the older text. The tenth: **one subagent per literary reference, not per critic.** Every thinker named in a panel critic, and every text in the LENSES cluster, is instantiated as its own subagent arguing from that author's own doctrine — a two- or three-name critic is two or three agents (`Critic: Apollonian Order (Wölfflin, Gombrich)` convenes Wölfflin and Gombrich separately) — and the panel must still meet the mode's composition rule. No reference may be merged into a composite voice, dropped, or reduced to a label; the run is not compliant while a required critic has never sat on the panel.

Four more are held here, pending an upstream resync that carries them; re-apply if a resync drops them. The eleventh: **Step 2g measures in the scope the figure claims** — a number taken on the artwork's file is not the number on the rendered page, and a count over the whole page is not a count above the fold; four of R9's six corrections were right numbers taken in the wrong scope. The twelfth: **the frame swap is a graph object**, not a rule in prose — `frame_swap` in the AUTONOMY subgraph, `CRITICS →|three objectors on one region| frame_swap`, `frame_swap →|re-opens| TRAVERSE`. The thirteenth: **an authority is seated only when it argues from its own doctrine on the page**; a name on an edge is a citation, and an objection about an unseated party stays open until that authority holds a verdict. The fourteenth: **an overrule names the trade in the object's own units** — what the refused move costs, measured, not that the objector's number is wrong.

Five more, from R10: the fifteenth, **a lens gives a text a literature and only a seat gives a name a summons** — `SKILL.md` draws critics from the CRITICS box and instantiates every LENSES text, so an authority the panel must be able to convene needs a node in LENSES *and* a seat in CRITICS, and filing a text under LENSES alone leaves it readable but unsittable; the sixteenth, **an overturn clause may name the graph and never the log** — `references/anchor-graph.md` is published and linked from the page, `DESIGN-LOG.md` is gitignored, so a clause testing the record must name a file the reader can open; the seventeenth, **print the zero with its denominator** — where the apparatus holds 0 of something, print `0` over the count it was taken from, so that adding or omitting an entry moves a number a reader can recompute; the eighteenth, **every verdict names the work it argues from** — an authority is a text and not a surname, and 0 of the 12 verdicts the page printed named one, so none of them was checkable; the nineteenth, **the composition rule convenes a seat that argues about who the canon omits**, `crit_erasure_miller` and `crit_erasure_walters`, as part of the panel rather than as a correction after it — a roster that cannot seat the party it leaves out will reproduce the omission on every run and call the result a finding.

Four more, from R11: the twentieth, **a verdict prints the work it argues from in an element of its own, and that element is a link to the record that holds it** — the eighteenth made an authority a text; the mechanism is a `<cite>` carrying the record's node id and line and resolving to a file the reader can already open, so a printed citation is traceable and not merely printed. The twenty-first: **where a citation is set is decided by measurement, not by convention** — a panel that splits between label, body and a line of its own is adjudicated by measuring every variant at the widths the object is read at and printing the cost of the one chosen, because insertion cost in a multi-column panel is non-linear. The twenty-second: **a documented work by a person of a surname is not that person** — an authority the record does not hold is not filled by a plausible candidate, and the refusal prints what it costs in the object's own units. The twenty-third: **seating an authority is a measurement of what it does to the equity figures the artifact prints** — a roster grown by four seats moved a printed share from 2 of 13 to 2 of 17, so convenability is not a reason to convene.

Three more, from R12: the twenty-fourth, **an entry moves every denominator that counts it** — filing one node carried the graph from 274 to 276 node lines and moved the canon count 11 → 12, the seats 25 → 26, the discharged verdicts 11 of 13 → 12 of 13, 10 of the 12 printed addresses, and the zero in the verdict that prints "0 of the 276"; a numerator corrected without its denominator is a figure no reader can recompute. The twenty-fifth, **a seat convenes one authority** — the tenth amendment makes one reference one subagent, so a critic node carrying two names is two seats (`crit_erasure` is now `crit_erasure_miller` and `crit_erasure_walters`), because a verdict that discharges one of the two leaves the other's objection open and the seat count is itself a printed figure. The twenty-sixth, **an entry into the record is printed at its address in the artifact that counts it** — the entered work's title went into the graph legend (canon titles printed on the page 0 of 11 → 1 of 12) rather than into a fourteenth verdict, which would have moved the equity figure 2 of 13 → 2 of 14 that the twenty-third governs.

Three more, from R13: the twenty-seventh, **a figure about the moving state is measured in motion** — the page printed 0.00% of the object's ink over the strip above 1000px, and that number had been taken at rest, where it is true and beside the point: in motion the sculpture crosses the description (2,305-4,451 px at 1001-1699), the edition chip at every width above 1000 (2,525-5,384 px) and the strip's second sentence on the way down (59-295 px), and not one of the three had ever been plated; a measurement taken at t=0 answers nothing about t>0, so the instrument drives every animation to the same instant of the fall and composites the object's own pixels under the word. The twenty-eighth, **a question asked three rounds running becomes a preset, not a probe** — `--preset cross` in `tools/measure.py` is that instrument, `total:0` is clean, and no later run rebuilds it by hand; reduced motion is a Chromium switch, not a snippet, so it is set with `CHROME_ARGS=--force-prefers-reduced-motion`. The twenty-ninth, **an entry moves every address behind it** — inserting 26 node lines into the graph left 8 of the 16 printed `node-id` links pointing at a real line that filed a different authority, so addresses are rebuilt from the record after any insertion, never renumbered.

`tools/measure.py` renders the site in headless Chromium against a **staged copy** with a fresh cache-bust token, then runs preset checks (`overflow`, `targets`, `bands`, `contrast`, `structure`, `state`, `cross`) or an arbitrary snippet at any list of widths. Use it to measure — never edit `web/` to take a measurement, and never leave scratch files in `web/`. Its `--fold` is the iframe height and so the viewport the snippet sees (omit it and every width reports 3,000px tall), and the `contrast` preset's `n` is the count of *failing* rows, so `n:0` is clean rather than unrun; both are stated in the module docstring.
