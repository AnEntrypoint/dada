05 / REVISE

An objection.

relationship.

Our first process strip looked like a fixed sequence. The Formalist objected: DADA branches, returns and reopens decisions.

The navigation now inspects moments, while the return loop expresses the actual method. The Provocateur’s demand for evidence brought this comparison into the artwork.

DADA keeps pushing and reviewing the whole until the stop conditions hold. This is one recorded revision, not a preset five-step limit.

01 Add the skill.

For agents that discover project skills in .agents/skills. Run from your project folder.

git clone https://github.com/AnEntrypoint/dada.git .dada-source
mkdir -p .agents/skills
test ! -e .agents/skills/dada && cp -R .dada-source/skills/dada .agents/skills/dada

Existing DADA installations are preserved. You can also copy skills/dada manually. Read setup instructions ↗

02 Bring an ambitious brief.

Start a fresh agent turn and invoke the skill. $dada is the token your agent recognises — keep it at the front of the prompt, then state your brief.
