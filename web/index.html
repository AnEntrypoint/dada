04 / CRITIQUE

resistance.

Critics judge the rendered work from contrasting positions. Every objection must name something observable.

The agent adapts, scraps or explicitly argues for the decision — adapt the work, scrap the move, or overrule the objection and print the measurement that refuses it. Changes reopen the choices that depend on them.

Eleven critics argued from opposed stances, and all eleven verdicts are printed here. One of them is not fully discharged.

05 / REVISE

An objection.
A stronger
relationship.

Our first process strip looked like a fixed sequence. The Formalist objected: DADA branches, returns and reopens decisions.

The navigation now inspects moments, while the return loop expresses the actual method. The Provocateur’s demand for evidence brought this comparison into the artwork.

DADA keeps pushing and reviewing the whole until the stop conditions hold. This is one recorded revision, not a preset five-step limit.

A FINISHED DESIGN. AN INSPECTABLE PROCESS.

Five artifacts.
Eleven critics. No quota.

You get the designed artifact, with the path that made it: a traversal plan, decision records, critic reports, an anchor ledger and a compliance check.

A traversal plan is the order the work was traversed, kept editable. A decision record ties one decision to the reason for it. A critic report names one observable thing per objection. An anchor ledger is every figure the page prints, with how to reproduce it. A compliance check is the list the run must satisfy before it may stop.

Identity. Posters. Editorial. Interfaces. Motion. DADA follows the needs of the work, with no fixed number of moves.

01 Add the skill.

Before you start: git, a terminal, and an agent that reads .agents/skills. Run from your project folder.

git clone https://github.com/AnEntrypoint/dada.git .dada-source
mkdir -p .agents/skills
cp -Rn .dada-source/skills/dada .agents/skills/dada

Existing DADA installations are preserved. You can also copy skills/dada manually. Read setup instructions ↗

02 Bring an ambitious brief.

Start a fresh agent turn and invoke the skill. $dada is the token your agent recognises — keep it at the front of the prompt, then state your brief.

$dada Create an extraordinary artistic webpage for my project. Follow the anchor graph, render the work, invite independent critics and keep refining until the whole composition converges. Make every decision earn its place.
